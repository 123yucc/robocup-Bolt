#### 1.2 奖励计算器 (`rl_reward_calculator.h/cpp`)

**功能**: 设计奖励函数用于RL训练

**奖励设计**:
| 事件 | 奖励值 | 说明 |
|------|--------|------|
| 进球 | +1000 | 极高奖励，核心目标 |
| 失球 | -1000 | 极高惩罚 |
| 获得控球 | +50 | 鼓励争夺球权 |
| 失去控球 | -30 | 惩罚丢球 |
| 传球成功 | +30 | 鼓励有效传球 |
| 球推进 | +5 * Δx | 前场推进奖励 |
| 球在危险区 | -20 | 防守压力惩罚 |

**关键代码**:
```cpp
RewardComponents RLRewardCalculator::calculateDetailedReward(
    const WorldModel & wm_before,
    const WorldModel & wm_after)
{
    // 1. Goal detection
    if (checkGoalScored(wm_after))
        rewards.goal_reward = 1000.0;
    
    // 2. Possession change
    if (!M_prev_had_possession && now_has_possession)
        rewards.possession_gain = 50.0;
    
    // 3. Ball advancement
    rewards.ball_advancement = (after_x - before_x) * 5.0;
    
    // 4. Defensive pressure
    if (ball_pos.x < -35.0)
        rewards.defensive_pressure = -20.0;
    
    return rewards;
}
```

### 3. Python训练管道 (`scripts/training_rl/`)

#### 3.1 训练脚本 (`train_rl_agent.py`)

**功能**: 使用Keras/TensorFlow进行DQN + Policy Gradient训练

**网络架构**:
```
输入: 350维特征
共享层: Dense(512) → LayerNorm → Dropout → Dense(256) → Dense(128)
Value头: Dense(1, linear)  → V(s)
Policy头: Dense(4, softmax) → π(s) [Pass/Shoot/Dribble/Hold]
```

**超参数**:
- 学习率: 0.0001
- 折扣因子: 0.99
- Batch size: 64
- 经验回放: 50000条

**关键代码**:
```python
class CyrusRLTrainer:
    def train_dqn_epoch(self, batch_size=64):
        # Compute TD targets
        td_targets = rewards + gamma * self.value_network.predict(next_states)
        
        # Update value network (critic)
        value_loss = self.value_network.train_on_batch(states, td_targets)
        
        # Compute advantages
        advantages = td_targets - current_values
        advantages = (advantages - mean) / std  # Normalize
        
        # Update policy network (actor)
        policy_loss = self.policy_network.train_on_batch(
            states, action_labels, sample_weight=advantages)
```

```cpp
bool SampleCommunication::sayRLIntention(
    PlayerAgent * agent, int action_index, const Vector2D & target)
```

